
# Student Study Tracker 📚

A student productivity web application built using Python, Flask, HTML, and CSS.

## About the Project

Student Study Tracker helps students record their study sessions, monitor their study time, organise tasks, and track their progress through a simple lavender-themed dashboard.

## Features

- Add study sessions with subjects, topics, dates, and durations
- View study history
- Calculate total study time
- View study time by subject
- Add tasks and mark them as completed
- Save information using JSON storage
- Validate user input
- Run automated Python tests

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JSON
- unittest

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Install the dependencies:

   pip install -r requirements.txt

5. Start the application:

   python app.py

6. Open http://127.0.0.1:5000 in your browser.

## Run the Tests

python -m unittest discover -s tests -v
